# T27 SFT-STC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement and smoke/locally validate T27 SFT Synthetic Table Condensation without violating the scalable SFT contract.

**Architecture:** Add a table-space STC layer under `shadow_hgc/sft/` that creates synthetic rows, constrains trainable deltas by SFT block, optimizes table-only objectives, and emits strict T27 CSV rows. Dataset scripts reuse existing lazy SFT memmap loaders and never consume teacher logits, validation/test labels, dense P2, full edge GPU tensors, or E-by-d materialization.

**Tech Stack:** Python, PyTorch in the local `pytorch` conda environment, existing SFT memmap stores, pytest, CSV/Markdown experiment outputs.
